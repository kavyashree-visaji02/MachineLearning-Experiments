# Machine Learning Experiments

## About
This repository contains Machine Learning experiments and practical work completed during college lab sessions. It includes Jupyter Notebook files (`.ipynb`) containing code, explanations, and outputs, along with the datasets used for the experiments.

## Contents
- **Jupyter Notebooks (`.ipynb`):** Source code and step-by-step implementations of experiments.
- **Datasets:** Data files used for data analysis, preprocessing, visualization, and Machine Learning tasks.
- **Experiment Outputs:** Results and visualizations generated while executing the notebooks.

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

This repository serves as a collection of classroom practicals, datasets, and implementations for learning, practicing, and revising Machine Learning concepts.
